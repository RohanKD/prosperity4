# Backtesting Tools

## Quick Start

```bash
# Install all backtesters
./backtesting/setup.sh

# Run the replay backtester (fastest, recommended for iteration)
./backtesting/run_replay.sh
```

## Available Tools

### 1. prosperity4btx — Replay Backtester (Recommended)

Replays your algorithm against historical market data. Fast, pip-installable.

```bash
pip install -U prosperity4btx
prosperity4btx trader.py 0          # round 0 = tutorial
prosperity4btx trader.py 0 --match-trades all   # match against all historical trades
```

Source: https://github.com/Xeeshan85/imc-prosperity-4-backtester

### 2. kevin-fu1 — Replay Backtester (Alternative)

OOP rewrite with detailed architecture. Clone-and-run.

```bash
cd backtesting/kevin-fu1-backtester
python -m prosperity4bt ../../trader.py 0
```

Source: https://github.com/kevin-fu1/imc-prosperity-4-backtester

### 3. chrispyroberts — Monte Carlo Backtester

Runs 100-1000 randomized simulations for statistical robustness testing. Requires Rust + Node.

```bash
cd backtesting/monte-carlo-backtester
# Follow their README for Rust/Node/uv setup, then:
prosperity4mcbt ../../trader.py --quick --out /tmp/dashboard.json
```

Source: https://github.com/chrispyroberts/imc-prosperity-4

### 4. jmerle Visualizer — Log Viewer (Browser)

Interactive web dashboard for viewing order books, trades, positions, and PnL over time. Works with output from any of the above backtesters.

**URL: https://jmerle.github.io/imc-prosperity-3-visualizer/**

Upload the `.log` file generated by a backtester run, or paste the log output directly.

The `Logger` class in `trader.py` outputs compressed JSON in the format the visualizer expects.
